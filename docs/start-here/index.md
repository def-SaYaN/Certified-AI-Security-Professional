## The 60-second version

If you only read one thing on this page, read this.

1. **Install the lab.** Follow [Lab Environment Setup](lab-environment.md) end to end,
   and make sure `python check_setup.py` prints all green.
2. **Read each chapter in order.** Concepts compound. Chapter 3 assumes Chapter 2.
3. **Do every lab.** Reading about prompt injection teaches you the words. Doing it
   teaches you the skill. The exam tests the skill.
4. **Take notes in your own words.** If you cannot explain a concept to a non-technical
   friend, you have not learned it yet.
5. **Ask questions early.** The [Mattermost community](support.md) is free and lifetime.

---

!!! danger "Rules of engagement — read before any lab"
    This course teaches genuine offensive techniques against AI systems.

    - **Only** run these techniques against the local, self-contained labs provided here,
      or against systems you own, or against systems where you hold **explicit written
      authorisation** to test.
    - Do **not** point these techniques at public AI services, your employer's production
      systems, or anyone else's infrastructure without permission.
    - Unauthorised testing is a crime in most jurisdictions, regardless of intent.

    Every lab in this course is designed to run entirely on your own machine precisely so
    that you never need to cross that line.
